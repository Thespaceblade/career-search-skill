# Refresh runbook

1. Read the profile, latest shared activity and relevant tracker records. Confirm the workspace path and which source connectors the user has enabled.
2. Run the configured discovery import. Review candidates from the feed, original posting, local links, or authorized accounts. Screen against actual requirements. Dedupe across the entire tracker and across the current run.
3. Prioritize verified recommendations. For each selected job, either record it for research or create an application package when requested. Only attach paths to files that exist. Leave raw candidates in the discovery queue until reviewed.
4. Reconcile statuses, deadlines, invitations and replies with explicit evidence when the required source is accessible. Stage any drafts and record the next actions. Keep historical application stages and preserve user edits.
5. Verify the dashboard shows the new records in the correct queue, including urgent roles, startup backlog, networking drafts and pipeline stages. Add a brief work log and report how many items were found, skipped, prepared or need attention.
6. If the user sets up a backup, run it to their chosen private destination and verify the archive. Keep access credentials outside the working tree.

Optional scheduler prompt: “Open my Career Search workspace and use the career-search skill. Run the refresh runbook with my configured sources and explicitly available read-only connectors. Verify employer links, identify new matching roles, and update local records from clear evidence. Flag missing access or ambiguous matches. Return application deadlines and drafts for my review.” Set the schedule through the agent's scheduling controls if requested.
